Página Web de Tecnologías para el Desarrollo Web

Este proyecto final consiste en el desarrollo de una página académica estructurada mediante HTML semántico, donde se sintetiza toda la información de una asignatura en un único archivo técnico.
El objetivo principal es demostrar el dominio de la jerarquía de contenidos y la correcta implementación de etiquetas específicas, desde la organización de temarios y planes de trabajo hasta la creación de tablas de evaluación detalladas y glosarios de términos.
A través de este ejercicio, se valida la capacidad para manejar entidades especiales y secciones de contacto, asegurando que la información sea accesible y legible para los navegadores.
En esencia, la asignatura proporciona los cimientos esenciales del desarrollo web, enfocándose en que la estructura del documento sea lógica, profesional y cumpla con los estándares actuales de la industria antes de avanzar hacia el diseño visual o la programación.

Temario de la Asignatura

  • HTML
  • CSS
  • JavaScript
  • JSON y Ajax
  • PHP

Plan de Trabajo de la Asignatura

  1. Desarrollo del lado Cliente (Frontend)
    1. HTML
    2. CSS
    3. JavaScript
  2. Desarrollo del lado Servidor (Backend)
    1. NodeJS Y Express
    2. BBDD NoSQL > MongoDB
